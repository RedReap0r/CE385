## ex1-callback.js

ไฟล์นี้ฝึกการทำงานแบบ Callback โดยใช้รูปแบบ error-first callback
มีฟังก์ชันค้นหานักศึกษาตามรหัส และทดสอบกรณีพบข้อมูล ไม่พบข้อมูล และรหัสไม่ถูกต้อง

ตอบเป็น comment ท้ายไฟล์:

1. ถ้าลืมตรวจ error แล้วอ่าน .name ทันที จะเกิดอะไรขึ้น ใครเห็น error นั้น?
   ตอบ: จะเกิด TypeError: Cannot read properties of undefined (reading 'name')
   เพราะเมื่อเกิด Error ค่า student จะเป็น undefined ทำให้โปรแกรม Crash (หยุดทำงานทันที)
   และผู้ใช้หรือระบบ Node.js จะเห็น Error นั้นพ่นออกมาทาง Console
2. ทำไมต้อง return หลังเรียก callback(error)?
   ตอบ: เพื่อหยุดการทำงานของฟังก์ชันต่อในทันที ป้องกันไม่ให้โค้ดบรรทัดถัดไป
   (เช่น คำสั่งค้นหาหรือการส่งค่าสำเร็จ) ทำงานซ้ำซ้อนหลังจากที่ส่ง Error ไปแล้ว

## ex2-promise.js

ไฟล์นี้ฝึกการใช้งาน Promise ด้วย `new Promise`
มีการจัดการผลลัพธ์ด้วย `.then`, `.catch`, `.finally` และการต่อ Promise หลายขั้นตอนด้วย chaining
นอกจากนี้ยังมีฟังก์ชัน `promisify` สำหรับแปลงฟังก์ชันแบบ callback ให้ใช้งานเป็น Promise

## ex3-async-await.js

ไฟล์นี้ฝึกการใช้งาน `async/await`
เปรียบเทียบการดึงข้อมูลแบบทำทีละรายการด้วย `for...of` กับการดึงข้อมูลพร้อมกันด้วย `Promise.all`
มีการจัดการข้อผิดพลาดด้วย `try-catch-finally`

ตอบเป็น comment ท้ายไฟล์:

1. ทำไม try-catch ครอบ await จับ reject ได้ แต่ครอบการเรียก callback ธรรมดาไม่ได้?
   ตอบ: เพราะ await จะหยุดการทำงานและแปลงสถานะ Rejected ของ Promise ให้กลายเป็น Error
   ที่สามารถโยน (throw) ออกมาได้เหมือนโค้ด Synchronous ปกติ ทำให้บล็อก try-catch จับได้
   ในขณะที่ Callback แบบเดิมทำงานแบบ Asynchronous แยกเธรด/คิวออกไป
   เมื่อเกิด Error ขึ้นใน callback ฟังก์ชันหลักจึงจบการทำงานไปแล้ว try-catch จึงดักจับไม่ทัน
2. ทดลอง "ลืม await" หน้า Promise.all แล้วเอาผลไปใช้ต่อ — เกิดอะไรขึ้น?
   ตอบ: จะได้ค่าออกมาเป็น Promise object แทนที่จะเป็น Array ของข้อมูลนักศึกษาจริงๆ
   ทำให้เมื่อนำผลลัพธ์ไปวนลูปหรือเรียกใช้ properties (เช่น .map หรือ .length)
   จะเกิด Error ว่าไม่สามารถอ่านค่าได้เพราะไม่ใช่ array

## ex4-combinators.js

ไฟล์นี้ฝึกใช้ Promise Combinators ได้แก่
`Promise.all` สำหรับงานที่ต้องสำเร็จครบทุกส่วน
`Promise.allSettled` สำหรับสรุปผลของทุกงานทั้งที่สำเร็จและล้มเหลว
`Promise.any` สำหรับเลือกผลลัพธ์จากงานแรกที่สำเร็จ
`Promise.race` สำหรับจำกัดเวลาและเลือกผลลัพธ์ที่เกิดขึ้นก่อน
